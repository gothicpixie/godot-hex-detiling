# Additional authored brick sources

Two native 1024² sources are prepared for controlled rendering tests. Their original diffuse, OpenGL normal, roughness and matching 16-bit displacement maps are copied without resizing or alteration. [material-sources.json](../material-sources.json) pins the exact download URLs, byte lengths, MD5 hashes, authors and recipe parameters; each source's provenance adds SHA256 hashes. This supplies real brick examples, not generated texture images.

**[Red Brick](https://polyhaven.com/a/red_brick)** is by Rob Tuytel / Poly Haven, [CC0](https://polyhaven.com/license), with a roughly 1.4 m source width reported by the primary API. It has smaller smooth red faces and darker, relatively narrow recessed mortar. Its authored safe-domain recipe thresholds matching displacement after subtracting a wrapped broad-height field; local smoothing sigma 1, broad sigma 24, residual threshold 200 in 16-bit height units. The mask adds a 1.5-pixel conservative distance guard and a 3-pixel smooth feather, then preserves fragments smaller than 1,000 pixels as original RGB. Two physical faces split by source pits would otherwise produce conflicting independent palette regions. Explicit, reviewed rectangles preserve both entire faces: `[546,414,712,461)` and `[379,723,539,766)`, in source pixels. The final mask has **119 eligible regions** and **50.89% fully protected pixels**. It does not claim every physical brick is eligible. Inspect [source/height/mask panels](red_brick/source-mask-review.png), [region annotation](red_brick/source-segmentation.png), and [provenance](red_brick/source-provenance.json).

**[Large Red Bricks](https://polyhaven.com/a/large_red_bricks)** is by Rob Tuytel / Poly Haven, CC0, with a 2 m source width. Larger chiseled clay faces, wider pale mortar, and deep face grooves provide a different geometry and surface-detail case. Height alone fragments some grooves or bridges some joints, so this is an explicitly color-assisted authored mask. It requires smoothed source red excess `R-(G+B)/2 > 45` in 8-bit source RGB units and matching height residual above −2,500 (local sigma 2, broad sigma 32). This is a source-specific material distinction, not a general semantic brick detector. The same guard, feather and fragment-preservation rules yield **72 eligible regions** and **36.50% fully protected pixels**. Pale face sections and deep damage can remain protected, reducing recoloring coverage. Inspect [source/height/mask panels](large_red_bricks/source-mask-review.png), [region annotation](large_red_bricks/source-segmentation.png), and [provenance](large_red_bricks/source-provenance.json).

Both masks use the actual aligned displacement; roughness is never interpreted as height. The large-brick displacement is a 16-bit gray+alpha PNG. OpenCV's unchanged decode retains its 16-bit gray values; the redundant RGB channels and nearly opaque alpha are validated, and alpha is not multiplied into height. The upstream alpha ranges only a few 16-bit steps below full opacity. All color processing still uses the independent original albedo RGB.

Both sources initially use only whole-source structure translations: period `(1,1)`, stagger zero. This preserves the supplied source motif without guessing a finer brick lattice. Source width is an authored physical-scale hint, not an inferred grid. New material support remains conditional on rendered color, edge, channel, minification and motion evidence.

Two other sources were assessed and rejected for this preparation pass. [Painted Brick](https://polyhaven.com/a/painted_brick), by Amal Kumar / Poly Haven under CC0, has chipped paint and height bridges that form large connected multi-brick regions under simple reviewed height recipes; those regions are not treated as individual bricks. [Slumped Mortar Brick](https://polyhaven.com/a/slumped_mortar_brick), by Dimitrios Savva / Poly Haven under CC0, has a near-uniform painted plateau and raised/slumped mortar that makes a simple positive-height interior rule unreliable. Their files remain temporary assessment downloads; neither is silently included as supported material. Height-only Large Red Bricks attempts were also rejected before the documented color-assisted recipe. Candidate rejection prevents damage patches or bridged joints from being called recognized bricks.

Regenerate the source copies, masks, packed albedos and panels with Python, Pillow, NumPy, SciPy and OpenCV:

```sh
python3 scripts/prepare_authored_brick_sources.py
```

The script downloads only the pinned 1K source maps when no matching existing file is present, verifies original hashes, refuses to overwrite differing source bytes, and records packed RGB/alpha equality. An optional `--cache /path/to/cache` reuses offline assessment copies organized by material ID. The packed masks follow the same independent-RGB/linear-alpha import contract as Brick 4. Atlas generation and its retained dimensions are recorded separately after the size-quality gate.
