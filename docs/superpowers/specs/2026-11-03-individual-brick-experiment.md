# Individual brick appearance experiment

User-approved local spike: vary actual individual brick appearance so the source's green/yellow patches stop recurring at each source repeat, without changing mortar. Keep default behavior and prior experiment available; no automatic merge, version/archive update or publication.

Segment the real source's toroidal brick interiors from its guard mask. Neutralize each brick's original robust RGB base and assign a balanced plausible source-derived replacement palette with an alpha-weighted feather. Bake a full-resolution 4×4 source atlas (4096²), including bricks crossing internal and outer boundaries. Native alpha-zero pixels must preserve original RGB exactly; preserve source fine-grain coordinates and original normal/roughness assets. Two baked palette seeds (0,7) support independent comparisons; demo uses primary palette 0; the harness manually binds palette7 for alternate-seed evaluation. The demo variation seed still controls stochastic world-layout offsets. No runtime IDs or integer decoding of filtered data.

The direct-atlas ablation repeats every four source spans (10m at test scale2.5m), costs about85.3MiB RGBA8 including full mipchain versus5.3MiB for one source, and is a bounded experiment rather than an unbounded production solution. Only one atlas is bound at a time. Measure original-source and full-atlas periods; do not conceal the new repetition scale.

Add default-off `brick_individual_enabled` and source-color mipmapped `brick_individual_map`. The new mode requires detiling, structure and guard enabled. It samples albedo at original projected UV/4 with derivatives/4, and original normal/roughness at original UV. Reconstruct normalized source slope as in the guarded source-only path. All three projection gradients precede sample calls. This intentionally bypasses coherent donor mixtures for aligned fine-detail PBR in the new mode, with nine full-PBR reads for direct-atlas ablation as a source-level count, not a timing claim. Primary mode uses `brick_individual_stochastic=true`: three palette atlas samples at integer source-tile offsets chosen by shared world-lattice vertex hashes, with continuous squared-and-renormalized barycentric weights from `detile_triangle_grid(uv/2)`. These offsets preserve exact geometry phase and break the fixed four-source color period without storing a larger atlas; colors can vary smoothly within a brick. At coarse triangle footprints, fade the whole color toward one shared atlas last-mip mean, never back to original repeating color. The alpha-zero color selection must precede this fade. Full PBR costs fifteen reads when resolved, up to sixteen with the one shared mean fetch. Finite atlas palettes and source geometry remain; do not claim mathematical aperiodicity. Protected/abovefade source channels remain matched; near interiors can differ from v0.7.0 donor PBR.
